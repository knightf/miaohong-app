# PWA 更新提示顶栏化设计

## 目标

解决移动端 PWA 新版本悬浮通知占用内容空间、操作层级过重的问题，同时保留离线缓存完成后的轻量反馈。

## 交互

- `needRefresh` 为真时，在现有顶栏操作区显示刷新图标按钮，不再渲染新版本悬浮通知。
- 图标使用品牌红色、柔和外发光和低频呼吸动画吸引注意；遵守 `prefers-reduced-motion`，用户要求减少动画时关闭呼吸效果。
- 按钮的可访问名称和原生提示均为“有新版本，点击更新”。桌面端 hover/键盘聚焦可看到提示，移动端点击直接调用现有 `updateServiceWorker(true)` 完成更新。
- `offlineReady` 仍使用现有悬浮通知，但取消手动“知道了”按钮；出现 3 秒后调用 `setOfflineReady(false)`，由 React 状态移除。视觉淡出由 CSS 动画完成，减少遮挡时间。

## 边界

- 不修改 Service Worker 注册方式、PWA manifest、缓存策略、应用 ID 或安装流程。
- 安装按钮和安装说明弹窗保持原样。
- 新版本状态不会被“稍后”隐藏，直到用户点击更新或 Service Worker 状态改变，顶栏图标持续可见。
- 离线通知与新版本状态可同时发生，互不阻塞。

## 验证

组件测试覆盖更新图标的出现、提示文案和点击更新，以及离线通知在 3 秒后自动关闭。样式测试覆盖光晕动画、减少动态效果和旧版更新浮窗操作的移除。最后运行完整测试、生产构建，并在亮色/暗色与移动端尺寸下做视觉检查。
